先记住这 4 句话

  1. 做分析，先定口径：统计什么、按什么分、和谁比较。
  2. 做透视表，先选维度和指标：地区是维度，金额是指标。
  3. 改数据，先查范围：UPDATE / DELETE 漏掉 WHERE，会影响全表。
  4. 写查询，先读懂题目：“自营”“每个分类”“前 5 条”都要落实到 SQL。

STUDY NOTES / 02

Excel：分组汇总，看清占比

重点：维度、指标、汇总方式、分母。

透视表四问：按什么分？统计什么？怎么汇总？占谁的比例？

1. 同比与环比

指标和谁比较增长率
同比去年同期（本期 − 去年同期）÷ 去年同期
环比紧邻的上期（本期 − 上期）÷ 上期

记住：销量上涨不等于某个人带来的效果；基期为 0 时不能直接套公式。

2. 透视表，按这 4 步做

  1. 整理数据：保留标题，用 Ctrl + T 转为超级表。
  2. 放字段：地区、渠道放行或列；金额、数量放值。
  3. 选汇总：金额求和、记录计数、最高消费取最大值。
  4. 查口径：占比看分母，新增数据后检查范围并刷新。

3. 占比看分母

假设：地区在行，性别在列。

想看什么值显示方式
各地区占全部金额多少总计百分比
每个地区内部的男女占比行汇总百分比
某一性别的金额分布在哪些地区列汇总百分比

4. 图表怎么选

比大小：条形 / 柱形　看时间趋势：折线　看少量类别占比：饼图。

大屏流程：透视表 → 图表 → 排版 → 切片器连接报表。

展开：电商练习的 5 类做法
  • 求和 / 最大值：地区金额、渠道订单量、渠道最大消费。
  • 交叉分析：地区 × 渠道；地区 × 性别。
  • 基准比较：与东北相比的百分比或差额。
  • 排序与分组：自定义地区顺序；日期按年、季度；年龄按区间。
  • 增长与累计：逐年增长选“上一项”；累计先明确排序。
易错：用户 ID 计数不一定是去重用户数；新增行列能否纳入，取决于数据源范围。
STUDY NOTES / 03

MySQL：先设计表，再存数据

重点：类型选对，约束写清。

数据库 → 表 → 字段与记录。字段是列，记录是行。

1. SQL 的四类用途

类别做什么关键词
DDL改结构CREATE / ALTER / DROP
DML增删改记录INSERT / UPDATE / DELETE
DQL查数据SELECT
DCL管权限GRANT / REVOKE（补充）

2. 常用类型

数据类型原因
编号、数量INT / BIGINT存整数，按范围选
姓名、手机号VARCHAR(n)存文本，保留前导零
固定长度编码CHAR(n)定长文本
金额DECIMAL(10,2)共 10 位，其中 2 位小数
日期 / 日期时间DATE / DATETIME按是否需要时分秒选择

记住：金额通常用 DECIMAL；DOUBLE 是近似浮点数。

3. 用一张表记住约束

CREATE TABLE users (
  id INT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(20) NOT NULL,
  phone VARCHAR(20) UNIQUE,
  gender VARCHAR(2) DEFAULT '男'
);

主键：唯一且非空　自增：自动生成编号
非空：不能是 NULL　唯一：限制重复值　默认：省略时使用预设值。

NOT NULL 不等于禁止空字符串；MySQL 的 UNIQUE 通常允许多个 NULL；自增不保证连续。

展开：连接与常用命令
mysql -h 127.0.0.1 -P 3306 -u 用户名 -p
-- 按提示输入密码

CREATE DATABASE IF NOT EXISTS study_lab
  CHARACTER SET utf8mb4;
USE study_lab;
SHOW TABLES;
DESC users;
SHOW CREATE TABLE users;

MySQL 默认端口通常为 3306。补充建议：新练习库使用 utf8mb4。

STUDY NOTES / 04

数据维护：先分清改什么

重点：ALTER 改结构，DML 改记录。

1. 改表结构：ALTER

-- 新增字段
ALTER TABLE users ADD age INT;
-- 重命名字段，并重新写明类型和属性
ALTER TABLE users CHANGE name user_name
  VARCHAR(20) NOT NULL;
-- 删除字段
ALTER TABLE users DROP COLUMN age;

2. 改记录：增、改、删

-- 增：明确列名，值一一对应
INSERT INTO users (user_name, phone)
VALUES ('张三', '13800138001'),
       ('李四', '13800138002');
-- 改：只给开发部涨薪
UPDATE emp_study
SET emp_salary = emp_salary + 1000
WHERE emp_dept = '开发部';

-- 删：工资等于 15000 的员工
DELETE FROM emp_study
WHERE emp_salary = 15000;
执行前先查：把相同 WHERE 放进 SELECT，核对范围。以上变更示例仅用于独立练习库；调薪重复执行会重复增加。

3. 三种“删除”别混淆

命令删除什么保留结构
DELETE … WHERE …满足条件的记录是
TRUNCATE TABLE全部记录，通常重置自增是
DROP TABLE整张表否

记住：UPDATE / DELETE 不写 WHERE，会影响全表；MySQL 的 TRUNCATE 会隐式提交，不能当作可回滚的普通删除。

STUDY NOTES / 05

SELECT：把题目拆成查询步骤

重点：先筛行，再分组，最后排序、取条数。

读题找关键词：“自营”→ WHERE；“每类”→ GROUP BY；“平均”→ AVG；“前 5”→ ORDER BY + LIMIT。

1. 一条 SQL 串起查询

SELECT category_id, AVG(score) AS avg_score
FROM products
WHERE is_self = '自营'       -- 先筛选商品
GROUP BY category_id        -- 再按分类统计
HAVING AVG(score) > 9.5      -- 筛选统计结果
ORDER BY avg_score DESC     -- 从高到低
LIMIT 5;                    -- 最多取 5 组

2. 条件怎么写

需求写法
同时满足 / 任一满足AND / OR；混用时加括号
999 到 4199，含两端price BETWEEN 999 AND 4199
几个指定值之一price IN (999, 2199, 4199)
以“华为”开头 / 包含“小”name LIKE '华为%' / name LIKE '%小%'
匹配一个字符LIKE 中用 _；% 匹配零个或多个字符
没有评分 / 已有评分score IS NULL / IS NOT NULL

3. 统计记住 5 个函数

COUNT 计数　SUM 求和　AVG 平均　MAX 最大　MIN 最小。

  • COUNT(*)：统计行数；COUNT(score)：只统计非空评分。
  • WHERE：过滤原始行；HAVING：过滤分组结果。
  • 初学时，SELECT 中非聚合列都写进 GROUP BY。

4. LIMIT：先跳过，再取出

-- 按价格降序，跳过 10 行，取 5 行
SELECT id, name, price
FROM products
ORDER BY price DESC, id ASC
LIMIT 10, 5;

分页：偏移量 =（页码 − 1）× 每页条数。LIMIT 5 表示取前 5 行。

展开：自营商品中评分最高的一条
SELECT id, name, score
FROM products
WHERE is_self = '自营' AND score IS NOT NULL
ORDER BY score DESC, id ASC
LIMIT 1;

并列最高时这里只取一条；“第二条记录”也不一定是“第二高的不同价格”。

STUDY NOTES / 06

重点纠错：先核对这 6 项

容易写错的不是长语句，而是条件和口径。

常见错误正确记法
开发部涨薪漏掉条件WHERE emp_dept = '开发部'
“工资等于 15000”写成 >emp_salary = 15000
“各分类内区分自营”只按自营分组GROUP BY category_id, is_self
LIMIT 两个参数记反LIMIT 偏移量, 条数
地区内部男女占比用列百分比地区在行时，用行汇总百分比
逐年增长固定对比 2017 年逐年比较用上一项；固定 2017 年是基期比较
展开：其他笔记修正
  • IF NOT EXISTS：不存在才创建；已存在才避免重复创建。
  • 删表写 DROP TABLE IF EXISTS 表名;，不是 IS EXISTS。
  • 看结构写 DESC 表名;，不是 SHOW TABLES。
  • 批量插入顺序：INSERT INTO 表名 (列名) VALUES (...), (...);。
  • 订单建表练习缺少价格字段，应补齐。
  • “自营最高评分”必须先加自营筛选。
  • 确认 orders 与 `order` 是否已重命名；库表名大小写统一。
  • 夏装选择题的答案存在冲突：数字只说明夏装销售额的同期和上期差异，不能判断经理能力或全部服装表现。
检查顺序：条件是否漏写 → 分组维度是否齐全 → 分母 / 基期是否正确 → 排序与条数是否符合题意。
STUDY NOTES / 07

5 道题，检查是否真正掌握

先自己回答，再展开答案。

01 · 环比上涨，能直接说明新店长做得好吗？

不能。环比只说明比上期上涨，不能直接证明因果。

02 · 地区在行、性别在列，如何看每个地区内部男女金额占比？

金额求和，值显示方式选择行汇总百分比。

03 · 为什么手机号用 VARCHAR，金额用 DECIMAL？

手机号是标识，需要保留前导零；金额需要精确的小数表示，并选择足够的位数。

04 · 查自营、价格在 999～4199 之间的商品，价格从高到低。
SELECT id, name, price
FROM products
WHERE is_self = '自营'
  AND price BETWEEN 999 AND 4199
ORDER BY price DESC, id ASC;
05 · 每页 5 条，查第 3 页，按价格降序。
SELECT id, name, price
FROM products
ORDER BY price DESC, id ASC
LIMIT 10, 5;

跳过 (3 − 1) × 5 = 10 行，再取 5 行。

最后自查

  • 能说清同比、环比和占比的分母。
  • 能选择字段类型，写出主键、非空、唯一约束。
  • 修改、删除前会先 SELECT 核对条件。
  • 能独立组合 WHERE、GROUP BY、HAVING、ORDER BY、LIMIT。

    理论

        创建数据库

            IF NOT EXISTS

      表操作
        创建数据库表格
          CREATE TABLE [IF NOT EXISTS] 表名(字段名称 数据类型 [约束][COMMENT 字段备注]......);
            数据类型
              常用类型
                int
                  整数
                bigint
                  整数
                  存储位数更大的整数
                varchar(x)
                  字符串
                  x可以控制字符串长度
                char(x)
                  字符串
                  x可以控制字符串长度
                datetime
                  时间
                decimal(x,y)
                  小数
                  x可以控制数据长度
                  y可以控制小数位数
                  注意
                    decimal可以保证精度
                double
                  小数
                区别
                  char表示固定长度的字符串，如char(3)，如果填充'ab'时会补一个空格为'ab '，3表示字符数
                  varchar表示可变长度的字符串，如varchar(3)，填充'ab'时就会存储'ab'，3表示字符数
                区别
                  decimal：定点小数，可指定总长度与小数位，精度不会丢失，适合金额
                  double：浮点小数，存储效率高，但存在精度误差，不适合财务数据
              拓展
                https://dev.mysql.com/doc/refman/8.0/en/integer-types.html

            约束
              理论
                数据类型本身就是一种约束，数据约束是指在数据类型限定的基础上额外增加的要求
              常用约束
                主键 primary key
                  唯一标识表中的一行记录。 MySQL 建议所有表的主键字段都叫 id， 类型为int
                主键自增auto_increment
                  设置主键自增之后，新增数据时，数据库会自动把id值加1
                非空 not null
                  此字段不允许填写空值。NULL表示空
                唯一 unique
                  此字段不能重复
                默认 default
                  不填写字段对应的值会使用默认值，如果填写时以填写为准
                  格式
                    default 值
                      如果值是文字需要使用引号包裹
            COMMENT
              可以对字段做出备注，方便知道字段的含义
              注意
                备注内容需要被引号包裹
                  例如：comment='字段名称'
            注意
              约束可以不写,但是数据类型必须写
              在SQL中有一些关键字,无法直接用于当做表名或者字段名,如果想要使用需要增加反引号进行包裹
                查看关键字
                  SELECT * FROM information_schema.KEYWORDS;
              表名称与字段名称需要用下划线命名法

    操作
      新增
        格式
          INSERT INTO 表(字段1,字段2,字段3....) VALUE(值1,值2,值3.....)
            指定字段插入,一次性插入一行
            注意
              字符串和日期的值必须加单引号
              如果字段为非空字段(not null),在新增时必须添加此字段
              主键如果不想指定可以设置为null,让MYSQL自行管理
              如果给了唯一约束,新增重复数据会报错
              主键约束如果手动添加指定值,会重新按照现在主键字段最大值进行计算
          INSERT INTO 表 VALUE(值1,值2,值3.....)
            不指定字段插入.一次性插入一行
            注意
              字段可以省略,如果省略则默认新增全部字段,填写值时也要填写同样数量,并且字段顺序要严格遵守
          INSERT INTO 表 VALUES(值1,值2,值3.....),(值1,值2,值3.....)...
            不指定字段插入,一次性插入多行
            注意
              VALUE变成了VALUES
              每一行数据之间使用逗号隔开
          INSERT INTO(字段1,字段2,字段3....) 表 VALUES(值1,值2,值3.....),(值1,值2,值3.....)...
            指定字段插入,一次性插入多行
          分别用上述四种方式,往学生表插入数据

      修改
        格式
          UPDATE 表名 SET 字段名=值,字段名=值 [WHERE 条件]
          WHERE用来加筛选条件,只拿满足条件的数据,不满足的数据过滤掉
            例如想要找价格大于1000的商品
              where price > 1000
          比较运算符
        注意
          update不添加条件就是修改全表,谨慎使用

      简单查询

          SELECT 表别名.字段名1,表别名.字段名2..... FROM 表名 as 表别名

      分组查询
        理论
          对多行数据做统计运算，把多条输入合并成一个结果的函数
        格式
          SELECT
分组字段,
聚合函数
FROM 表名
GROUP BY 分组字段,...
[HAVING 条件]
            HAVING可以对分组后聚合函数进行过滤,WHERE只能对分组前的数据进行过滤
          关键字
            GROUP BY
              分组
            HAVING
              分组后过滤
        注意
          GROUP BY分组聚合分为两步：先分组，再聚合
            先分组：把表数据按照指定列的值进行划分，值相同的数据划分到同一个组
            在聚合:分别针对每一组数据使用聚合函数进行统计
          分组之后，SELECT后面查询的字段，必须满足下列2种情况之一
            字段是分组字段【即在GROUP BY之后出现】
            字段被聚合函数统计【聚合函数(字段)】
        需求
          统计每个分类中自营商品和非自营商品的平均价格
            select
            is_self,
            avg(price)
            from products
            group by is_self;
          统计每个分类商品的平均评分，并筛选平均评分大于9.5的分类
            select
            category_id,
            avg(score)
            from products
            group by category_id
            having avg(score) > 9.5;

        理论
          获取查询结果中指定范围内的行
        格式

字段列表
FROM
表名
LIMIT N,M
            M:表示开始索引,默认是0,代表从第M+1行开始
            N:表示查询条数,提取多少条数据
          关键字
            LIMIT
        注意
          当LIMIT所查询的数据不存在时,不报错只是没有数据
          如果从头开始M可以省略不写
        需求

            from products
            order by price desc
            limit 1,1;

            *
            from products
