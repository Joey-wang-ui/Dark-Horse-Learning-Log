# Dark Horse Learning Log

数据分析 DAY01–DAY08 学习手册：Excel、MySQL、SQL 多表查询与函数、FineBI 和电商分析项目。

- 8 天学习路径、12 个章节、页内导航与键盘翻页
- 每日重点、纠错、9 道复习题及 8 份原笔记文字索引
- 全文搜索（Ctrl / ⌘ + K）、SQL 高亮与一键复制
- 已掌握标记、复习清单、阅读位置与深色模式自动保存
- 手机抽屉目录、打印 / PDF，以及离线阅读

学习进度保存在各自浏览器，不上传、不跨设备同步。浏览器不允许本地存储时，仍可阅读和搜索。
章节使用稳定标识；此前四天版的掌握标记、阅读位置、复习勾选和分享链接会继续对应原内容。

## 文件与更新

- `index.html`：学习内容与页面结构
- `assets/style.css`：主题、响应式布局与打印样式
- `assets/app.js`：搜索、导航、代码复制及本地进度

修改后提交到 main，GitHub Pages 会自动部署。若浏览器仍显示旧版，刷新页面。
离线阅读时需要保留 index.html 和 assets 目录；无需外部字体、库或联网资源。

## 发布设置

Settings → Pages → Deploy from a branch → main → / (root)。

原始笔记可能包含错误，阅读时请结合重点纠错页。SQL 变更示例仅用于独立练习库。
