# Dark Horse Learning Log

数据分析 DAY01–DAY04 学习总结，依据个人 XMind 笔记整理。

- 左侧章节目录、上下页与键盘翻页
- 每日重点、SQL 示例、易错点和复习题
- 支持手机阅读、离线打开和打印

## 发布

在仓库 Settings → Pages 中，选择 Deploy from a branch，分支 main，目录 / (root)。

启用并部署后，访问：https://Joey-wang-ui.github.io/Dark-Horse-Learning-Log/
